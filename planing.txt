--------------------------------------------------------------------------------
PRODUCT GOAL (Tujuan Utama)
--------------------------------------------------------------------------------
Membangun web app pemesanan mandiri (self-order) dan sistem kasir/admin untuk 
Warung Sembako Duniawi dengan alur:
1. Pembeli memilih barang (sembako, rokok, es krim, roti, dll) dari katalog cerah.
2. Checkout tanpa ribet daftar akun (Guest checkout: Nama & WhatsApp).
3. Pilihan pengambilan: "Ambil di Warung" (aktif) & "Diantar" (Coming Soon).
4. Pembayaran di kasir (keterangan: QRIS, Tunai, Transfer).
5. Notifikasi real-time bunyi ke layar pemilik warung saat ada pesanan baru.
6. Fitur cetak struk otomatis/manual ke thermal printer kasir (58mm/80mm).

--------------------------------------------------------------------------------
TEKNOLOGI STACK (Tech Stack)
--------------------------------------------------------------------------------
- Framework: Next.js (App Router, TypeScript)
- Styling: Tailwind CSS + Google Fonts kustom (warm, modern, cerah)
- Database: SQLite / PostgreSQL via Prisma ORM (sangat ringan di Docker)
- Real-time Alert: Server-Sent Events (SSE) / Polling ringan dengan Audio Chime
- Thermal Printing: CSS Media Print 58mm/80mm + ESC-POS Web Print ready
- Container: Docker & Docker Compose (siap tandem di home server)
